# Quantitative Portfolio & Risk Analytics Project

**Take-Home Assessment | Central Bank of the United Arab Emirates (CBUAE)**

An end-to-end quantitative finance and portfolio analytics project completed as part of the recruitment process for the Central Bank of the UAE. The assessment covers portfolio optimisation, asset return predictions, transaction processing, and an institutional dashboard built in Power BI.

---

## 📁 Directory Structure

```text
